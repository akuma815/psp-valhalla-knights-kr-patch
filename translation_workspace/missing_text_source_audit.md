# 누락 문자열 소스 전수 조사 보고서

## 선택지 재확인

- `네놈, 내 이름을 아느냐?` 뒤의 `예 / 아니요`는 `etstrtbl` 171~172번을 사용한다. 현재 빌드는 원본 주소 `0xB60 / 0xB68`을 보존하며 첨부 화면에서도 두 항목이 한글로 출력된다.
- 이후 빈 선택지는 모두 `예 / 아니요`를 재사용하는 구조가 아니다. 별도의 메뉴·선택 안내문, 마법 계통명, 아이템명 같은 고정 데이터가 화면에 삽입된다.
- TSQV 611개 레코드의 일본어 문자열 슬롯을 원본과 다시 대조했다. 추출 대상 4,998개는 기존 `tsqv_translation.csv`에 전부 존재하며 TSQV 문자열 슬롯 누락은 0개다.

## 추가 원인

- `rebuild_fixed_name_tables.py`가 고정 테이블 행을 문자 매핑 입력에 중복 추가하고 있었다.
- 이 때문에 고정 테이블에 저장된 한글 코드와 `fonttbl`/GIM의 글리프 코드 순서가 달라져, 번역이 있는 아이템명도 빈칸 또는 다른 문자로 출력될 수 있었다.
- 중복 입력을 제거하고 전체 빌드를 다시 수행했다. 기존 무기·몬스터·인물·마법·일반 아이템 계열 7개 테이블 610개 항목은 저장 바이트와 설치된 폰트 매핑이 610/610 일치한다.
