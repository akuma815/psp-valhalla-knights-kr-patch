# STTV 고정 슬롯 초과 해결 TASK

## 목표

`total_translation.csv`의 기존 테이블 번역 1,517행을 잘림 없이 `tbldata.res`에 삽입합니다.

상위 RESC 레코드의 위치와 크기는 유지하고, 17개 `STTV1.00` 레코드 내부에서 문자열 오프셋과 길이만 가변 재구성합니다.

## 현재 기준 상태

- 고정 슬롯 초과 번역: 초기 280개 / ASCII 문장부호 2바이트 매핑 적용 후 286개
- 최대 초과량: 15바이트
- 고유 한글: 850자
- 재구성 후 원본보다 커지는 STTV: 0개
- 가장 여유가 적은 테이블: `wpstrtbl` 24바이트
- 인코딩 불가 문자: `·` 16개 (`qtstrtbl`)
- `tbldata.res` 원본 크기: 163,840바이트

## 실행 순서

아래 TASK는 번호 순서대로 하나씩 실행합니다. 각 TASK의 통과 조건을 만족하기 전에는 다음 TASK로 넘어가지 않습니다.
