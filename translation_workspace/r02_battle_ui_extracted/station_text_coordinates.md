# station0·station2 일본어 좌표 및 번역 입력 안내

번역은 `station_text_translation.csv`의 `Translated` 열에 입력합니다. 다른 열과 ID는 변경하지 않습니다.

좌표 기준:

- 원점 `(0,0)`은 이미지 왼쪽 위입니다.
- 사각형은 `X, Y, Width, Height` 순서입니다.
- `station0` 크기: 512×512
- `station2` 크기: 256×256
- `Original`의 `\n`은 이미지 안의 줄바꿈입니다.
- `S2_022 ユキメ`는 작은 픽셀 글자라 판독 신뢰도가 중간이며 번역 전에 재확인을 권장합니다.
